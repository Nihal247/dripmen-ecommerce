# DripMen E-commerce 🛒

A full-stack eCommerce website built using modern web technologies.

## 🚀 Tech Stack

* Frontend: HTML, CSS, JavaScript
* Backend: Node.js, Express
* Database: MongoDB
* Payment: Razorpay
* Auth: JWT + Google OAuth
* Image Upload: Cloudinary

## ✨ Features

* User authentication
* Admin panel
* Product management
* Cart & Wishlist
* Online payment integration
* Image upload with Cloudinary

## 📦 Setup

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

Open:

```
Public/User/index.html
```

## 🔐 Environment Variables

Create `.env` inside backend:

```
PORT=
MONGO_URI=
JWT_SECRET=
RAZORPAY_KEY_ID=
CLOUDINARY_CLOUD_NAME=
```
